## Description of the project

Espresso XR is an interactive virtual reality training experience developed using Godot. The project aims to teach users the fundamental steps involved in preparing espresso using a traditional espresso machine.

Learners will interact with virtual coffee-making equipment to practise the preparation process, including dosing, tamping, attaching the portafilter and extracting espresso.

The experience will aim to provide step-by-step guidance and feedback to help learners understand and remember the correct procedure.
